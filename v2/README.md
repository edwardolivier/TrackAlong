# TrackAlong v2 — Web App

FastAPI backend + React frontend, containerised for Google Cloud Run.

> **Status:** In development.

## Stack

- **Backend:** FastAPI (Python) — wraps the v1 core logic as a REST API
- **Frontend:** React + Leaflet + Plotly.js
- **Auth:** Google OAuth (ID token verified server-side)
- **Hosting:** Google Cloud Run
- **CI/CD:** GitHub Actions — deploys to Cloud Run on push to `main`
